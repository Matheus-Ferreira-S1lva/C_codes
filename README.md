Desafios de Lógica em C

Este repositório contém soluções de desafios de programação e simuladores de sistemas reais, focados em lógica, estruturas de dados básicas e algoritmos.
--------------------------------------------------------------------------
1. Simulador de Pontuação (Beecrowd 1367)

Sistema que processa logs de maratona de programação para calcular acertos e penalidades.

    Destaque: Conversão de caracteres para índices de array (letra - 'A') para gestão de 26 problemas simultâneos.

    Lógica: Implementa regras de penalidade (20 min por erro) e controle de estado (evita pontos duplicados após o acerto).

    Tecnologias: C, string.h, Arrays, while com flag de parada.
----------------------------------------------------------------------------
2. Monitor de Combustível de Aeronaves

Simulador de telemetria básica para balanceamento de carga entre as asas de um avião.

    Destaque: Uso de Operador Ternário para alertas de segurança imediatos.

    Lógica: Processamento de arrays com acumuladores para validar a autonomia total de voo.

    Tecnologias: C, Vetores, Laços de repetição, Lógica condicional otimizada.
----------------------------------------------------------------------------
3. Sistema de Check-in e Controle de Peso

Protótipo de sistema para pesagem de bagagens com foco em segurança operacional.

    Destaque: Interrupção de fluxo em tempo real (break) caso o limite crítico de 100kg seja atingido.

    Lógica: Validação individual de excesso de carga (acima de 23kg) por item.

    Tecnologias: C, Arrays, for, Verificação de limites e entrada formatada.
----------------------------------------------------------------------------
Por que esses projetos?

Estes códigos fazem parte da minha jornada de transição para a TI, onde aplico conceitos fundamentais de Ciência da Computação (como os vistos no curso CS50 de Harvard) para resolver problemas práticos e lógicos.
